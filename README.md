### Overview

This repository contains the standalone frontend application for the **Rajasthan Royals SupeRR Selector Season 2 (Round 1)** challenge.

The intelligence platform adapts cross-sport methodologies—specifically **NBA Regularized Adjusted Plus-Minus (RAPM)** and **MLB Leverage Index (LI)**—into a unified **Pressure Context Adjusted Impact (PCAI)** engine. It decouples raw baseline talent from situational pressure performance across 48,290 high-leverage deliveries.

---

### Features & Architecture

1. **Command Center**:
   - Executive delivery counters, clutch separation lifts, and bootstrap stability indicators.
   - Spotlights on **Tim David** (#1 Batter, PCAI 94.70) and **Sufiyan Muqeem** (#1 Bowler, PCAI 95.09).
   - 2D Bayesian Regularized Skill Decomposition ($\alpha$ vs $\delta$ and $\beta$ vs $\theta$).

2. **Batter Intelligence**:
   - Ranked roster of the Top 10 pressure-reliable batters.
   - Decoupled scoring impact: Baseline Strike Rate vs Pressure Strike Rate vs Clutch Lift $\delta$.
   - Interactive Linear/Bloomberg data grid with sortable columns and in-cell score bars.

3. **Bowling Intelligence**:
   - Ranked roster of the Top 10 pressure-reliable bowling suppressors.
   - Run containment and wicket acceleration metrics under death leverage.
   - Squeeze factor $\theta$ vs baseline economy differentials.

4. **The Pressure Lab (1v1 Simulator)**:
   - Interactive over-by-over matchup simulator pairing any batter against any bowler.
   - Computes win probabilities, ball-by-ball outcome distributions (boundaries, dots, singles, wickets), and tactical coaching directives.
   - Multi-variable empirical context coefficients trained on 48,290 deliveries.

5. **Head-to-Head 1v1 Battle Arena**:
   - Side-by-side comparative analysis with dual radar overlays and valuation comparisons.

6. **Player Database & Roster Directory**:
   - Complete 20-player directory with verified real-world sports media cutouts, career stats, and IPL 2027 auction projections.

### Tech Stack

- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom glassmorphism primitives
- **Visualizations**: Recharts (Radar, Scatter, Trajectory Lines)
- **Icons**: Lucide React
- **Build Tool**: Vite 6

### Quick Start

```bash
# Clone the repository
git clone https://github.com/Dineshkumar-jb/RR_DASHBOARD.git
cd RR_DASHBOARD

# Install dependencies
npm install

# Start local development server
npm run dev

# Or build for production
npm run build
npm run preview
```
